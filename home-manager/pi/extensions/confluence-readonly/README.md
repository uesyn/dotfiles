# Confluence Cloud read-only tool

The `confluence` Pi tool lists spaces, searches pages and retrieves a page by ID. It is disabled by default; `/tool confluence` enables it for the session. It is available in plan mode but not to subagents; enable it before entering plan mode because `/tool` changes are blocked while plan mode is active. Operations are fixed GET requests; this is not a sandbox and does not restrict other tools or the account itself.

Set `dotfiles.pi.confluence.cloudId` to the site's UUID and use a scoped personal API token. The API destination is fixed to `https://api.atlassian.com`; unscoped tokens are not supported. The Cloud ID is written to the Nix store. Set `CONFLUENCE_EMAIL` and `CONFLUENCE_API_TOKEN` in Pi's environment; never put credentials in Nix. Pi-web must receive them when its server starts. Scoped tokens need permissions for [space listing](https://developer.atlassian.com/cloud/confluence/rest/v2/api-group-space/) (`read:space:confluence`), [search](https://developer.atlassian.com/cloud/confluence/rest/v1/api-group-search/) and [page retrieval](https://developer.atlassian.com/cloud/confluence/rest/v2/api-group-page/); the account also needs access to the relevant pages.

`list_spaces` takes optional `limit` (1–25, default 25) and `cursor`. `search` takes literal `query`, optional `space`, `limit` (1–25, default 10), and `cursor`. Pass `nextCursor` from the previous result with the same operation and, for search, the same query and space. `get_page` takes a numeric `pageId`. Page bodies are Confluence storage-format HTML, truncated at 60,000 characters. Network responses are limited to 2 MiB, requests time out after 30 seconds, and redirects are rejected. When the API provides a usable site base URL, links are constructed from that untrusted response data for display; otherwise links are omitted. Links and cursors returned by the server are never followed as request URLs. No automatic retries are performed.

Some model-facing tool schemas require every property even when it is marked optional. Unused string arguments may be omitted or set to `""`; the tool removes empty string placeholders before core validation. `query` is still required for `search`, and `pageId` is still required for `get_page`. A schema-valid `limit` is ignored for `get_page`. Non-empty arguments belonging to another operation and unknown arguments are still rejected.

Results are untrusted external content, may contain prompt injection or sensitive data, and are sent to the model and saved in the Pi session. The tool's read-only interface does not restrict other uses of the token; select only the scopes required. Credentials are not intentionally included in errors, but remain in the Pi process environment.

Tests: set `PI_TEST_PACKAGE_DIR` to the installed Pi package directory, then run `node --test --import ./home-manager/pi/extensions/ast-grep/tests/register.mjs home-manager/pi/extensions/confluence-readonly/tests/*.test.ts`. Tests use mocked HTTP and do not connect to Confluence.
